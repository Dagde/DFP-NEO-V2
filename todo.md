# Mock Data Investigation

## Current Issue
User reports that after fixing trainee schedules, mock data appears to be included (up to 50 trainees). User wants this verified and fixed if necessary.

## Investigation Findings

### Mock Data Source
- `ESL_DATA` is generated by `generateDataSet('ESL')` in `mockData.ts`
- ESL mock data contains 89 trainees:
  - ADF301: 25 trainees (15 RAAF + 5 Navy + 5 Army)
  - ADF302: 25 trainees (18 RAAF + 7 Navy + 0 Army)
  - ADF303: 25 trainees (20 RAAF + 5 Navy + 0 Army)
  - FIC 210: 4 trainees (4 RAAF)
  - FIC211: 10 trainees (8 RAAF + 2 Navy)

### Current Code State
Line 254 in `lib/dataService.ts`:
```typescript
trainees = mergeTraineeData(trainees, ESL_DATA.trainees, true);
```

The third parameter `true` enables mock data inclusion.

### mergeTraineeData Logic
- Tags DB trainees with `_dataSource: 'database'`
- Only adds mock trainees if `includeMockData` is true
- Deduplicates by `idNumber` (mock only added if no DB trainee with same idNumber exists)
- Tags mock trainees with `_dataSource: 'mockdata'`

## Completed Tasks
- [x] Determined that mock data should be excluded from trainee list
- [x] Changed line 254 parameter from `true` to `false`

## Summary
Fixed the mock data inclusion issue by changing the `includeMockData` parameter in `mergeTraineeData` from `true` to `false`. This prevents the 89 mock trainees from ESL_DATA from being added to the trainee list. The fix has been built and committed.
